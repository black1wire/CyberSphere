# Персональний проєкт: CyberSphere (Лендінг IT-послуг)

### Опис проєкту
Сучасний, адаптивний односторінковий веб-сайт (лендінг) для технологічної компанії CyberSphere, яка займається кібербезпекою, аудитом систем та розробкою захищеного софту. Проєкт реалізовано з упором на чисту семантику та сучасні тренди в UI/UX дизайні.

### Посилання на макет Figma
[Посилання на базовий концепт у Figma](https://www.figma.com/community/file/1192534570763260888)

### Технологічний стек та вимоги
* **HTML5**: Семантичні теги (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`).
* **CSS3**: Flexbox, Grid, CSS-змінні для легкої кастомізації.
* **Валідація**: Код оптимізовано під вимоги W3C (без критичних помилок).
* **Чуйність**: Повна адаптивність під мобільні пристрої та планшети.
